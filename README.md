# KanbanBoard

## Постановка задачи

Канбан-доска задач в реальном времени. Три колонки: «К выполнению», «В работе», «Готово». Пользователь вводит имя, добавляет задачи, перетаскивает их между колонками и удаляет. Кто взял задачу в работу, тот исполнитель. Готовые задачи двигать нельзя. Все, у кого открыта доска, сразу видят изменения и уведомления о действиях других. 
Задачи хранятся в SQLite.
