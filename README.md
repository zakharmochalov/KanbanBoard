# KanbanBoard

## Постановка задачи

Канбан-доска задач для совместной работы. 

На доске три колонки (статусы задач): «К выполнению», «В работе», «Готово». 

Пользователь вводит имя, добавляет задачи, перетаскивает их между колонками и удаляет. Исполнителем задач становится тот, кто взял задачу в работу. Готовые задачи перемещать нельзя. 

Все, у кого открыта доска, сразу видят изменения и получают уведомления о действиях других пользователей. На странице также показывается, сколько пользователей сейчас онлайн.
